# Dzieło Biblijne

Mobile app made in React Native

---

### Configuration

Before starting the application, it is necessary to create an `.env` file, based on `.env.sample` file:

```
API_URL=api_address
```

To start the application, execute the command:

`npx react-native run-android`

or

`npx react-native run-ios`

### Versioning

Application versioning scheme:

**major.minor.patch**

eg.**1.0.1**

To create new version, before build use this command:

`yarn version (major|minor|patch)`
